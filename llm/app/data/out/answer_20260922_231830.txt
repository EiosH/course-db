Collections: Fold Left vs. Fold Right

How does Scala implement foldLeft and foldRight?

package scala.collection
trait LinearSeqOps[A, +CC[X] <: LinearSeq[X],
  +C <: LinearSeq[A] with LinearSeqOps[A, CC, C]] {
  // ...
  override def foldLeft[B](z: B)(op: (B, A) => B): B = {
    var acc = z
    var these: LinearSeq[A] = coll
    while (!these.isEmpty) {
      acc = op(acc, these.head)   // <-- Ed.: Lipstick on a pig.
      these = these.tail
    }
    acc
  }
}

package scala.collection.immutable.List
sealed abstract class List[+A] extends /* ... */ {
  // ...
  final override def foldRight[B](z: B)(op: (A, B) => B): B = {
    var acc = z
    var these: List[A] = reverse   // <-- Ed.: Lipstick on a pig.
    while (!these.isEmpty) {
      acc = op(these.head, acc)     // <------ Airbrushed!
      these = these.tail
    }
    acc
  }

  final override def reverse: List[A] = {
    var result: List[A] = Nil
    var these = this
    while (!these.isEmpty) {
      result = these.head :: result
      these = these.tail
    }
    result
  }
}

The length of the resulting list is **2N**.

Here is the breakdown:
1.  **Base Case:** If the input list is `Nil` (length 0), the result is `Nil` (length 0). This fits the formula $2 \times 0 = 0$.
2.  **Recursive Step:** For a non-empty list `y :: ys` (where `ys` has length $N-1$), the function returns `y :: (y :: f(ys))`.
    *   It adds the head element `y` twice.
    *   It then appends the result of `f(ys)`.
    *   If we assume `f(ys)` has length $2(N-1)$, then the total length is $2 + 2(N-1) = 2N$.

So, for every element in the original list, the function produces two copies of that element in the output list.

The length of the resulting list is **M + N**.

Here is the breakdown:
1.  The function `f` recursively traverses the first list `xs`.
2.  For every element in `xs` (there are `M` of them), it prepends that element to the result of the recursive call.
3.  When `xs` becomes `Nil`, the function returns `ys` (which has length `N`).
4.  Therefore, the final list consists of all `M` elements from `xs` followed by all `N` elements from `ys`.

Essentially, `f` is a list concatenation function (equivalent to `xs ++ ys`).
