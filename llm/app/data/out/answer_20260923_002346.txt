Collections: Fold Left vs. Fold Right

How does Scala implement foldLeft and foldRight?

package scala.collection
trait LinearSeqOps[A, +CC[X] <: LinearSeq[X],
  +C <: LinearSeq[A] with LinearSeqOps[A, CC, C]] {
  // ...
  override def foldLeft[B](z: B)(op: (B, A) => B): B = {
    var acc = z
    var these: LinearSeq[A] = coll
    while (!these.isEmpty) {
      acc = op(acc, these.head)   // <-- Ed.: Lipstick on a pig.
      these = these.tail
    }
    acc
  }
}

package scala.collection.immutable.List
sealed abstract class List[+A] extends /* ... */ {
  // ...
  final override def foldRight[B](z: B)(op: (A, B) => B): B = {
    var acc = z
    var these: List[A] = reverse   // <-- Ed.: Lipstick on a pig.
    while (!these.isEmpty) {
      acc = op(these.head, acc)     // <------ Airbrushed!
      these = these.tail
    }
    acc
  }

  final override def reverse: List[A] = {
    var result: List[A] = Nil
    var these = this
    while (!these.isEmpty) {
      result = these.head :: result
      these = these.tail
    }
    result
  }
}

The length of the resulting list is **3N**.

Here is the breakdown:
1.  **Base Case:** If the input list is `Nil` (length 0), the result is `Nil` (length 0). This fits the formula $3 \times 0 = 0$.
2.  **Recursive Step:** If the input list has a head `y` and a tail `ys` (where `ys` has length $N-1$), the function returns `y :: (y :: (f(ys)))`.
    *   This adds **2** elements (`y` and `y`) to the front of the list returned by `f(ys)`.
    *   By induction, if `f(ys)` has length $3(N-1)$, then the total length is $2 + 3(N-1) = 2 + 3N - 3 = 3N - 1$. Wait, let's re-evaluate.

Let $L(N)$ be the length of the result for an input list of length $N$.
*   $L(0) = 0$
*   $L(N) = 2 + L(N-1)$ for $N > 0$

This is an arithmetic progression:
*   $L(1) = 2 + L(0) = 2$
*   $L(2) = 2 + L(1) = 4$
*   $L(3) = 2 + L(2) = 6$

The pattern is $L(N) = 2N$.

Let's double-check the code:
```scala
case y::ys => y::(y::(f (ys)))
```

It prepends `y` twice. So for every element in the original list, two elements are added to the result.

Therefore, the length of the resulting list is **2N**.

*   `?1` is `List[X]`
*   `?2` is `X => Y`
*   `?3` is `List[Y]`

The complete function signature is:
```scala
def g[X, Y](xs: List[X], f: X => Y): List[Y] =
  xs match
    case Nil     => Nil
    case y :: ys => f(y) :: g(ys, f)
  end match
end g
```
This is essentially the `map` function for lists.
