    *   The function is `xs => xs`, which returns `Iterable[X]`. So `B` is `X`.

The lecture didn't provide a simpler code example; instead, it focused on deconstructing the complex implementation to show why it feels like "glorified iteration."

If you're looking for the core concept without the `var`/`while` implementation details, think of it this way:
*   **`foldLeft`** is just a loop that accumulates a result from left to right.
*   **`foldRight`** is the same, but it reverses the list first (which is why the instructor called it "lipstick on a pig" or "airbrush," as it's less efficient).

The instructor used these examples specifically to highlight that they *aren't* simple, purely functional operations under the hood, but rather efficient loops.
